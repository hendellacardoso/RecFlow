# Code signing policy / Política de assinatura de código

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Assinatura de código gratuita fornecida pela [SignPath.io](https://about.signpath.io), com certificado da [SignPath Foundation](https://signpath.org).

## Team roles / Funções da equipe

| Role / Função | Member / Membro |
|---|---|
| Committers and reviewers / Autores e revisores | [Hendell A. Cardoso](https://github.com/hendellacardoso) |
| Approvers / Aprovadores | [Hendell A. Cardoso](https://github.com/hendellacardoso) |

- Only binaries built from this repository by GitHub Actions are signed (`.github/workflows/release.yml`).
- Every signing request is approved manually by an approver.
- All team members use multi-factor authentication on GitHub and SignPath.

- Somente os instaladores gerados a partir deste repositório pelo GitHub Actions são assinados.
- Cada pedido de assinatura é aprovado manualmente.
- Todos os membros usam autenticação em dois fatores no GitHub e no SignPath.

## Privacy policy / Política de privacidade

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Este programa não transfere nenhuma informação para outros sistemas em rede, a não ser quando solicitado expressamente pelo usuário ou por quem o instala ou opera.
