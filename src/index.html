    O módulo uiohook-napi não está instalado, então os efeitos de clique ficam desativados. Rode npm install novamente.

    Teclas pressionadas

    Dica: ative a opção acima ao digitar senhas durante a gravação.

    Desenho, efeitos de clique e teclas aparecem nos modos Tela inteira e Área.

    Atalhos de teclado

    Clique no campo e pressione a nova combinação. Teclas comuns precisam de Ctrl, Alt ou Shift. Backspace remove o atalho.

    Gravação agendada

    O gravador precisa estar aberto (pode ficar na bandeja). Usa o modo e as configurações atuais.

    Marcações para manual

    Enquanto grava (ou mesmo sem gravar), aperte Insert com o cursor no campo que quer explicar: o RecFlow pausa a gravação, tira um print, contorna o campo, numera e pede a explicação. Ao confirmar, a gravação continua.

    Insert marca o campo em foco na tela atual
    Shift+Insert começa uma tela nova (novo print)

    Os atalhos podem ser trocados na aba Atalhos. Se o campo não for identificado, é só arrastar sobre ele para marcar.

    Título do manual

    O nome de cada tela é pedido no primeiro item dela. Tudo pode ser ajustado depois no editor de manual.

    Arquivos gerados

    Cada gravação gera uma pasta com tela_01.png, tela_02.png… (prints com as marcações), descricoes.txt (número e explicação), manual.html (manual pronto para abrir ou imprimir) e a pasta originais com os prints sem marcação.
